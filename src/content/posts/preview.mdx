> 이 글은 디자인 검증용 초안입니다. Steven이 작성한 실제 글이 아니며 운영 사이트에는 발행되지 않습니다.

## 매일의 질문을 남기는 곳

긴 글만 기록일 필요는 없습니다. 오늘 생긴 작은 질문이나 직접 시도해 본 것들도 충분한 시작입니다.

**명확하게 읽히는 글**, 편안한 여백, 그리고 필요한 만큼의 색으로 구성했습니다.

## 코드를 담을 때

```ts
const thoughts = ['질문하기', '직접 해보기', '기록하기'];
for (const thought of thoughts) {
  console.log(thought);
}
```

- 직접 경험한 것과 추측을 구분하기
- 시간이 지나도 다시 읽을 수 있는 기록 남기기
- [Astro 문서](https://docs.astro.build/)처럼 참고한 자료 연결하기
